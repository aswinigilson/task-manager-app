# Task Manager Application

A task management application built with Python.

## Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Store task data
=======
A console-based Task Manager Application built using Python. The application allows users to create, view, update, and delete tasks. Task data is stored persistently in a JSON file.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks with confirmation
- Validate user input
- Store tasks persistently using JSON
- Handle invalid inputs and file-related errors
- Object-oriented Task representation
- Modular project structure

## Task Details

Each task contains:

- Task Name
- Description
- Priority

Priority values:

- High
- Medium
- Low
